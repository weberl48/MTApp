## SECTION 2: Sessions

### What it does:
This is where you view, create, and manage all therapy sessions.

### Things to test:

#### A) Viewing Sessions
- [ ] Click "Sessions" in the sidebar
- [ ] Can you see the list of all sessions?
- [ ] Try the search bar - search for a client name or contractor
- [ ] Try the filters (Status, Contractor, Date Range)
- [ ] Click on a session to view its details
- [ ] Try switching between "List" and "Calendar" view

#### B) Creating a New Session
- [ ] Click "New Session" button
- [ ] Select a service type from the dropdown
- [ ] Add one or more clients as attendees
- [ ] Set the date and time
- [ ] Set the duration
- [ ] Check that the pricing calculates automatically (you should see Total, MCA Cut, Contractor Pay)
- [ ] Add some notes
- [ ] Save the session

#### C) Editing a Session
- [ ] Find an existing session and click "Edit"
- [ ] Change something (like the date or notes)
- [ ] Save your changes
- [ ] Verify the changes were saved
